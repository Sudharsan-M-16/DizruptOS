# DIZRUPT — Startup Investment Memo (VC lens)

**Recommendation: PASS at today's stage; strong WATCH / pre-seed candidate IF the team
gets one real org using it weekly.** This is a tech-risk-retired, market-risk-wide-open bet.

## Thesis
Org tools track *work*; they don't *reason* about the organization. DIZRUPT computes
explainable intelligence (succession/bus-factor/blast-radius/decision-memory/simulation)
over a typed org graph. If populated with real data, that history compounds into a moat
incumbents can't retrofit. Foundry proves enterprises pay for this; nobody owns mid-market.

## What's de-risked (genuinely impressive)
- **Technical risk: low.** Clean architecture, 9 intelligence engines, memory graph,
  multi-tenant RLS, 137 tests — built and verified. The hard *engineering* is done.

## What's NOT de-risked (the whole investable risk)
- **No users. No data. No revenue. No design partner. No named founder/market fit.**
- **No distribution motion.** "Org intelligence platform" ≠ a wedge.
- **Unfalsified intelligence** — scores never checked against real outcomes.
- **Operational/identity gaps** (no auth, no deploy) — it can't be used by an outsider today.

## What would make me invest (concrete milestones)
1. One real organization's data ingested + a manager using the executive surface weekly.
2. Evidence the intelligence **predicted something true** (a flagged succession risk that mattered).
3. A sharp wedge + 3 design partners + a repeatable "aha" in <10 minutes.
4. Real auth + a path to land via existing tools (sit on top of Jira/HRIS).

## Brutal investor truth
The build quality could make a founder *overconfident*. Beautiful architecture is not
traction. The next dollar of effort should buy **a real user on real data**, not a tenth
intelligence engine. Time-to-first-real-org is the only metric that matters now.
