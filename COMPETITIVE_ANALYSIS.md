# DIZRUPT — Competitive Analysis (honest)

DIZRUPT is NOT a task tracker. Positioning it against Jira/Linear on task UX loses.
Its only honest wedge: **computed, explainable organizational intelligence** (succession
risk, bus factor, blast radius, decision memory, simulation) that task tools structurally
lack. It should sit *on top of* the system of record, not replace it.

| Competitor | DIZRUPT wins | DIZRUPT loses | Must build to win |
|---|---|---|---|
| **Jira** | reasoning, org graph, succession/bus-factor, decision memory | ubiquity, integrations, workflows, mobile, maturity, users | Jira import/sync; sit above it |
| **Linear** | org-intelligence; nothing on task craft | world-class speed/craft/polish; real users | don't compete on tasks; integrate |
| **Asana** | computed risk/health/dependency | adoption, marketing, ecosystem | portfolio-intelligence layer over Asana data |
| **ClickUp** | focus + reasoning | feature breadth, price, scale | a sharp single job, not breadth |
| **Monday** | explainable intelligence vs dashboards | low-code flexibility, GTM machine | keep "reasoning not dashboards" promise |
| **Notion/Airtable** | opinionated computed intelligence | flexibility, adoption, ecosystem | don't be a flexible DB |
| **Palantir Foundry** | speed-to-value, mid-market focus, price | scale, data integration, security, services, brand | the existential threat; win on focus+self-serve before Foundry moves down-market |
| **Glean / Glean-likes** | structured org *reasoning* vs search | retrieval breadth, connectors, funding | GraphRAG over the memory graph |

## The honest competitive truth
- DIZRUPT's defensibility is **the populated graph + memory + engines**, realized only
  with real customer data. Empty, it's a months-to-clone demo.
- First-mover advantage is **zero** without users. The moat compounds per-customer-month
  of real organizational history — so **time-to-first-real-data is the whole game.**
- Best wedge: "**See the people/capability/decision risk Jira can't.** Connect your tools;
  we tell you what's fragile, who's irreplaceable, and what breaks if they leave."
